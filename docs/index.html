Opening, editing and sharing your transcript

Start: export SRT from Buzz, then open it here with the original audio. Keep the recording untrimmed so its timestamps match. M4A support depends on the audio codec and browser; if a recording will not play, use an MP3 or WAV copy with the same timeline.

Edit: click Edit beside a sentence, then Apply. This changes its wording, not its timestamps. Ctrl+Enter applies an edit; Escape cancels. Search filters the list; clear it to follow the whole conversation. Loop repeats the selected sentence.

Save: download SRT to preserve wording and timestamps. A project file also stores the expected audio filename and playback position, but does not contain the recording. TXT is a reading copy with timestamps. Downloads do not overwrite the original automatically. Closing or reloading this tab discards unsaved edits.

Share: send the reader HTML file, the audio, and the corrected SRT (or project) together. The recipient opens the HTML in Edge or Chrome and selects those files. No Buzz installation, model download or transcription is needed. A hosted version works the same way: files are selected locally and are not uploaded by this reader.
